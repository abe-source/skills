Reusable AI-agent skills I've built and use day to day — methodologies and step-by-step instructions for specific tasks, written tool-agnostic and packaged up once they're generalized enough to be useful to anyone, not just tied to my own setup.

## What's in here

Each entry is a canonical markdown skill: a description of when to use it, plus the instructions for carrying out the task. It's written to be dropped into whatever AI coding tool you use, with a short adapter note per entry on how to wire it into that tool's specific mechanism — Claude Code's [Agent Skills](https://docs.claude.com/en/docs/claude-code/skills) (`SKILL.md`, auto-discovered from `~/.claude/skills/`), Cursor's project rules, Codex CLI's custom instructions, or just pasted in as a system prompt.

The skill itself is the source of truth; the adapter note is a thin translation layer, not a duplicate copy per tool.
